# Abandono Escolar en Argentina

Proyecto de análisis y visualización interactiva de la **Tasa de Abandono Interanual en Argentina**, desarrollado con R y Shiny a partir de datos educativos oficiales.

## 🎯 Objetivo

Explorar la evolución del abandono escolar y facilitar la comparación entre jurisdicciones, niveles educativos y ciclos lectivos mediante un tablero interactivo.

## 📊 Funcionalidades

El tablero permite:

- Comparar la tasa de abandono entre jurisdicciones.
- Analizar la evolución temporal por provincia.
- Comparar los niveles Primario y Secundario.
- Filtrar la información por provincia, nivel educativo y año lectivo.
- Explorar los datos mediante una tabla interactiva.
- Consultar el marco metodológico utilizado para interpretar el indicador.

## 🛠️ Tecnologías utilizadas

- R
- Shiny
- shinydashboard
- ggplot2
- Plotly
- dplyr
- DT

## 📚 Fuente de datos

Datos abiertos de la Secretaría de Educación de Argentina.

Período analizado: **ciclos lectivos 2003-2004 a 2023-2024**.

👉 [Acceder al tablero Abandono Escolar en Argentina](https://pye3fg-eduardo-arnica.shinyapps.io/abandono/)

## 📐 Nota metodológica

La Tasa de Abandono Interanual analiza el flujo de estudiantes entre dos años lectivos consecutivos. Los valores negativos que pueden observarse en determinadas jurisdicciones deben interpretarse considerando los movimientos interanuales de matrícula entre jurisdicciones, ámbitos o sectores de gestión.
